GitHub only tracks files, so to create a folder for the GUI, just "Add file", and then create your folder name (followed by a /), and then the name of a file (such as readme.md). The other method is to use "git pull", create the folder on your local machine, and then "git push" to put it on GitHub. I highly recommend that you use "git pull" and "git push" to download to your local machine. The basic operations are:
 
```
git clone <name of repo>
<go into the repo folder>
<make your changes>
git add .
git commit -m "My updates"
git push
```
 
Once set up, you can then just use git pull to update your local version:
 
```
git pull
```
